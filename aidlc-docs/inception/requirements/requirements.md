# Requirements — Phase 1（確定 2026-06-27）

## オーナー回答
- メモ構成: **自由記述1欄のみ**（Markdown）
- 自動タグ（日本語モチーフ）: **公開**（公開ギャラリーで誰でも絞り込み可）
- 既存592枚バックフィル: **埋め込み＋日本語タグ（一度きり ≈$10）**
- 検索方式: **ADR-002 で比較して決定**（この時点では保留）

## 機能要件 (FR)
- **FR-1** 画像1件=1レコードのメタデータ（memo / autoTags / visibility / uploadedAt / embedding）を保持する
- **FR-2** 管理モード（`?admin`＋Basic認証）で、各画像に自由記述メモを編集・保存できる
- **FR-3** メモは公開/非公開トグル（**デフォルト非公開**）。画像自体は公開のまま
- **FR-4** アップロード画像から**日本語モチーフタグを自動生成**（公開）
- **FR-5** 公開ギャラリーで**タグ絞り込み**ができる
- **FR-6** 「モチーフ名」での**意味検索**（手動タグ不要、例「山並み」）
- **FR-7** 既存592枚に埋め込み＋タグを**バックフィル**（一度きり）

## 非機能要件 (NFR)
- **NFR-1 低コスト**: 継続増分 ≈$0〜1/月。検索のランニングコストは実質ゼロ
- **NFR-2 プライバシー**: 非公開メモは公開CDNから到達不能。**公開フラグ付きだけ**を公開JSONに射影
- **NFR-3 後方互換**: 既存の公開ギャラリー・iOSアップロード経路を壊さない
- **NFR-4** 単一ユーザー前提

## 制約
- Terraform = IaC 正本、apply はオーナー
- 別アプリ image-share-app（ImageUploader系）には触れない

## スコープ外（Phase 2以降）
- リファレンス写真管理 / 写真↔絵の類似サジェスト / 動画・GIF / 3D表示
